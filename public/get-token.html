获取123云盘Token

用于 GitHub Actions 镜像脚本自动登录

方式一（推荐）· 浏览器控制台

用手机浏览器打开 123pan.com 并登录，然后复制下面这段代码：

javascript:var t=localStorage.getItem("token")||localStorage.getItem("authorization")||JSON.parse(localStorage.getItem("user")||"{}").token;if(t){prompt("复制下面这行Token:",t)}else{alert("未找到Token，请先登录123pan.com")}

长按上方代码 → 全选 → 复制。然后在浏览器地址栏粘贴并回车。

如果浏览器阻止了 javascript: 协议，请用方式二

方式二 · 此页面直接提取

前提：你已经在同一浏览器中登录过 123pan.com

方式三 · 手动查找

1. 用手机浏览器打开 www.123pan.com 并登录

2. 在地址栏输入（先复制好）：

javascript:alert(JSON.parse(localStorage.user).token)

3. 如果弹出了很长一串文字，复制下来就是 Token

拿到Token后

去 GitHub 仓库 → Settings → Secrets and variables → Actions → Secrets

新建一个 secret：Name = PAN123_TOKEN，Value = 粘贴Token

然后手动触发 "Mirror to 123pan" workflow 即可（不需要填手机号密码了）
