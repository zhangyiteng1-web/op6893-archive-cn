获取123云盘Token

用于 GitHub Actions 镜像脚本

方式一 · 书签法（手机可用）

1. 添加一个书签，名称随意，网址填下面这段：

javascript:(function(){var t=JSON.parse(localStorage.user||'{}').token;if(t){var e=document.createElement('textarea');e.value=t;e.style.position='fixed';e.style.top='0';e.style.left='0';e.style.width='100%';e.style.height='200px';e.style.zIndex='99999';e.style.background='#111';e.style.color='#0f0';e.style.fontSize='12px';e.style.padding='10px';document.body.appendChild(e);e.select();e.setSelectionRange(0,99999);navigator.clipboard.writeText(t);alert('Token已复制: '+t.substring(0,30)+'...')}else{alert('未找到，请先登录123pan.com')}})();

2. 打开 123pan.com 并登录

3. 点击那个书签，Token 会自动复制并弹出

方式二 · 电脑浏览器（最简单）

在电脑上登录 123pan.com，按 F12 → Console，粘贴下面代码回车：

JSON.parse(localStorage.user).token

输出的那串文字就是 Token，复制即可。

方式三 · 手动输入

如果你能通过其他方式获取 Token，直接粘贴到下方：

拿到Token后

去 GitHub 仓库 → Settings → Secrets → Actions → Secrets

新建 PAN123_TOKEN，粘贴 Token

然后触发 "Mirror to 123pan" workflow
